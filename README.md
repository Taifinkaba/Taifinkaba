## 🚀 Featured Project

### 🔥 WOS Tools

A web application designed to help Whiteout Survival players calculate the resources required for building upgrades.

* Built with **Next.js, TypeScript, and Tailwind CSS**
* Calculates resource requirements for building upgrades
* Simplifies calculations players would otherwise have to perform manually
* Designed with accessibility and usability in mind

👉 [Check out WOS Tools](https://wos-tools.vercel.app/)
